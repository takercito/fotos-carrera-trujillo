# Fotos carrera infantil · Trujillo · 24/10/2026

Web estática (GitHub Pages) para que las familias encuentren y descarguen las fotos de la carrera.

- Galería completa ordenada por hora de captura; búsqueda por número de dorsal.
- Fotos sin metadatos EXIF/GPS. La web no se indexa en buscadores (`noindex` + `robots.txt`).
- Uso personal, no comercial.

¿Quieres que retiremos una foto? Escribe a j.quesada.rod@gmail.com indicando el nombre del archivo (p. ej. IMG_5768.jpg).
